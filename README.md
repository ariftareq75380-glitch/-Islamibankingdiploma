# Islami Banking Diploma (ইসলামী ব্যাংকিং ডিপ্লোমা)

IBB (Institute of Bankers, Bangladesh) পরিচালিত ইসলামী ব্যাংকিং ডিপ্লোমা (JAIBB / DAIBB) পরীক্ষার পূর্ণাঙ্গ প্রস্তুতি পোর্টাল, হ্যান্ডনোট, অতীতের প্রশ্ন সমাধান, মক টেস্ট এবং সিলেবাস গাইড।

## 🚀 বৈশিষ্ট্যসমূহ (Features)
- 📚 JAIBB ও DAIBB এর সব বিষয়ের সিলেবাস ও চ্যাপ্টারভিত্তিক রিসোর্স
- 📝 আগের বছরের প্রশ্ন এবং মডেল উত্তর (Downloadable PDF)
- 🎯 ইন্টারেক্টিভ কুইজ ও সেলফ-অ্যাসেসমেন্ট মক টেস্ট
- 🔍 আধুনিক সার্চ ও ফিল্টারিং ব্যবস্থা
- ⚡ Vercel / Netlify / Cloudflare Pages এ এক ক্লিকে ডিপ্লয়মেন্ট সুবিধা
- 🌐 অল-ইন-ওয়ান SEO অপটিমাইজেশন (Google Search Engine Ready)

## 💻 GitHub এ আপলোড করার নিয়ম (Step-by-Step GitHub Upload)

### ধাপ ১: গিট রিপোজিটরি শুরু করুন (Terminal এ)
```bash
git init
git add .
git commit -m "Initial commit for Islami Banking Diploma portal"
git branch -M main
```

### ধাপ ২: GitHub এ নতুন রিপোজিটরি তৈরি করুন
1. [GitHub.com](https://github.com) এ লগইন করুন।
2. **New Repository** বাটনে ক্লিক করুন।
3. নাম দিন: `islamibankingdiploma` (অথবা আপনার পছন্দমতো)।
4. **Create repository** ক্লিক করুন।

### ধাপ ৩: গিটহাবে পুশ করুন (GitHub Push)
GitHub এ দেখানো কমান্ড অনুযায়ী নিচের কোডটি আপনার টার্মিনালে চালান (`YOUR_USERNAME` এর জায়গায় আপনার গিটহাব ইউজারনেম দিন):
```bash
git remote add origin https://github.com/YOUR_USERNAME/islamibankingdiploma.git
git push -u origin main
```

## 🌐 Vercel-এ ফ্রি কাস্টম ডোমেইন দিয়ে লাইভ করার নিয়ম

1. [vercel.com](https://vercel.com) এ যান এবং GitHub দিয়ে লগইন করুন।
2. **"Add New Project"** সিলেক্ট করুন।
3. আপনার `islamibankingdiploma` রিপোজিটরিটি সিলেক্ট করে **"Import"** চাপুন।
4. **"Deploy"** এ ক্লিক করুন। মাত্র ১ মিনিটের মধ্যে আপনার সাইট লাইভ হয়ে যাবে!
5. **Project Settings -> Domains** এ গিয়ে `islamibankingdiploma.vercel.app` নাম সেট করুন।
